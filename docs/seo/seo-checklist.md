# SEO优化检查清单

> 全面的SEO检查清单，确保网站在搜索引擎中获得最佳表现。适用于新功能发布、定期检查和问题排查。

## 🔍 技术SEO基础

### Robots.txt配置
- [ ] robots.txt文件可正常访问 (`/robots.txt`)
- [ ] 允许搜索引擎爬取重要页面
- [ ] 正确禁止爬取敏感目录（`/api/*`, `/admin/*`）
- [ ] 包含sitemap链接
- [ ] 阻止AI训练爬虫（如需要）

### Sitemap配置
- [ ] XML sitemap可正常访问 (`/sitemap.xml`)
- [ ] 包含所有重要页面
- [ ] URL格式正确（完整的绝对路径）
- [ ] lastModified时间合理
- [ ] 优先级设置恰当
- [ ] 已提交到Google Search Console

### 页面结构
- [ ] 每页只有一个H1标签
- [ ] 标题层级合理（H1 → H2 → H3...）
- [ ] 内部链接结构清晰
- [ ] 面包屑导航（如适用）
- [ ] 404页面友好且有导航

## 📝 内容SEO

### 页面元数据
- [ ] **Title标签**: 每页唯一、包含关键词、长度适中（50-60字符）
- [ ] **Description**: 每页唯一、吸引人、包含关键词（150-160字符）
- [ ] **Keywords**: 相关且不过度堆砌
- [ ] **Canonical URL**: 设置正确，避免重复内容
- [ ] **Language标签**: 正确设置页面语言

### Open Graph和Social Media
- [ ] `og:title` - 社交媒体标题
- [ ] `og:description` - 社交媒体描述
- [ ] `og:image` - 高质量分享图片（1200x630px）
- [ ] `og:url` - 规范化URL
- [ ] `og:type` - 页面类型（website/article等）
- [ ] Twitter Card配置

### 结构化数据
- [ ] 适当的Schema.org标记
- [ ] FAQ页面使用FAQPage schema
- [ ] 产品页面使用Product schema
- [ ] 组织信息使用Organization schema
- [ ] 通过Google Rich Results测试

## 🚀 性能SEO

### 页面速度
- [ ] **Core Web Vitals通过**:
  - [ ] LCP < 2.5秒
  - [ ] FID < 100ms
  - [ ] CLS < 0.1
- [ ] 图片优化（WebP格式、适当尺寸）
- [ ] 启用压缩（Gzip/Brotli）
- [ ] 缓存策略合理
- [ ] CSS和JS最小化

### 移动友好性
- [ ] 响应式设计
- [ ] 移动设备可用性测试通过
- [ ] 触摸目标足够大
- [ ] 文字大小适中
- [ ] 避免使用Flash或其他不兼容技术

## 🔗 链接SEO

### 内部链接
- [ ] 重要页面有足够内部链接指向
- [ ] 锚文本相关且多样化
- [ ] 避免过度优化的锚文本
- [ ] 链接层级不超过3层
- [ ] 无死链接

### 外部链接
- [ ] 外链使用`rel="nofollow"`（如适用）
- [ ] 避免链接到低质量网站
- [ ] 新窗口打开外链（`target="_blank"`）
- [ ] 检查反向链接质量

## 🌐 多语言SEO（如适用）

### Hreflang标签
- [ ] 正确的语言代码（en-US, zh-CN等）
- [ ] 所有语言版本相互链接
- [ ] 包含x-default版本
- [ ] URL结构一致

### 内容本地化
- [ ] 每种语言的独立SEO优化
- [ ] 文化适应性考虑
- [ ] 本地关键词研究
- [ ] 正确的货币和日期格式

## 🛡️ 安全性SEO

### HTTPS配置
- [ ] 全站HTTPS
- [ ] 有效的SSL证书
- [ ] HTTP到HTTPS重定向
- [ ] HSTS头部设置
- [ ] 混合内容检查

### 其他安全措施
- [ ] 适当的CSP（内容安全策略）
- [ ] X-Frame-Options设置
- [ ] 防止爬虫过度抓取

### 其他工具
- [ ] PageSpeed Insights检查
- [ ] Mobile-Friendly Test通过
- [ ] Rich Results Test通过
- [ ] 定期SEO审计

## 🎯 内容质量

### 用户体验
- [ ] 内容原创且有价值
- [ ] 解决用户实际问题
- [ ] 易于阅读和理解
- [ ] 适当的内容长度
- [ ] 相关的内部链接

### 技术内容质量
- [ ] 无拼写和语法错误
- [ ] 图片有描述性alt文本
- [ ] 视频有字幕（如适用）
- [ ] 表格有适当的标题
- [ ] 列表结构清晰

### 每周检查
- [ ] GSC索引覆盖率
- [ ] 新增404错误
- [ ] 网站速度监控
- [ ] 重要页面排名

### 每月检查
- [ ] 完整的SEO审计
- [ ] 竞争对手分析
- [ ] 关键词排名报告
- [ ] 技术问题修复

### 重大更新后
- [ ] 重新提交sitemap
- [ ] 检查所有重定向
- [ ] 验证新页面索引
- [ ] 监控流量变化

## 🚨 紧急情况处理

### 索引大幅下降
1. [ ] 检查robots.txt是否被误改
2. [ ] 验证服务器是否正常
3. [ ] 检查是否有大量404错误
4. [ ] 查看GSC错误报告

### 流量突然下降
1. [ ] 检查Google算法更新
2. [ ] 分析竞争对手变化
3. [ ] 审查最近的网站更改
4. [ ] 检查技术问题

### 页面无法被索引
1. [ ] 使用URL检查工具诊断
2. [ ] 检查robots.txt限制
3. [ ] 验证页面质量
4. [ ] 手动请求索引

- [ ] 已添加到sitemap

- [ ] 移动设备测试通过
