## 📝 Screenshot Guidelines

### 📸 For Developers

If you're contributing screenshots, please follow these guidelines:

1. **Resolution**: Minimum 1920x1080 for desktop screenshots
2. **Mobile**: Use iPhone 12/13 Pro dimensions (390x844)
3. **Format**: WebP preferred, PNG acceptable
4. **Compression**: Optimize for web without quality loss
5. **Naming**: Descriptive filenames (e.g., `homepage-hero-desktop.webp`)

### 🎯 Screenshot Locations
```
public/images/
├── hero-showcase/     # Homepage hero section
├── scenarios/         # Template examples
├── examples/          # Before/after comparisons
└── gallery/          # User creation gallery
```

*All screenshots should showcase the live platform at [sybaupicture.com](https://sybaupicture.com)*
